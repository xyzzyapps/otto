Finally, a command line shell that speaks plain English.

otto is an ultra-fast, zero-filler interactive login shell and systems language. It replaces bash, fish, rg, fd, eza, bat, jq, delta, just, and direnv with one zero-dependency C11 binary and readable English sentences.

1. Implicit Stdin Pipeline Loop (-n)

Everything Built-in. Zero Dependencies.

One static binary that replaces modern developer CLI tools, Fish interactive ergonomics, and beginner tutorials out of the box.

💡

Fish-Class Interactive Shell

Starship-style prompt, inline ghost autosuggestions, cycling Tab completion menu (verbs, $ENV, git, paths), Ctrl+R fuzzy history, persistent ~/.otto/history, and live abbr expansions.

abbr "gs" "read status, table" • prepend "~/.local/bin" into $PATH
🔍

rg, fd, eza & bat Built-in

Recursive .gitignore-aware search, rich stat file metadata with unit literals (10kb, 7d, :8080), and syntax-highlighted view with a built-in terminal pager.

search casefold "TODO" in "src", table.
stat "src/*", sort size descending, table.
🌿

Structured Git, TOML, JSONL & Crypto

Query status, commits, branches, and delta-colored diff as native maps. Parse JSON, YAML, CSV, TOML, and streaming JSONL, plus hash, encode/decode, and uuid.

read git commits, take 5, table.
"hello", hash sha256 • read "Cargo.toml" toml
🛠️

Ports, Disk, .env & Ottofile Tasks

Inspect open sockets (read ports), mounted drives & folder sizes (disk), auto-load .env files on cd, and run documented project recipes with otto --tasks / otto task.

every port where port == :8080: kill.
disk "src", table. • otto task deploy prod
🎓

Built-in Tutor, Cheat Sheets & Hints

Learn in 5 minutes with otto tutor, browse offline docs via help & examples, and get visual ^~~~ caret diagnostics, typo suggestions, and Bash-to-Otto Rosetta tips.

otto tutor • help search • examples git
⚖️

Dual Preposition Flexibility

Write how your brain thinks. Choose concise zero-preposition transitive style or explicit prepositional phrasing with 100% bytecode equivalence.

replace "8080" "9090" ↔ replace "8080" with "9090"
search "TODO" "src" ↔ search "TODO" in "src"
🔗

Pronoun Register Anaphora

Chain multi-sentence pipelines naturally: it refers to active value, that carries the previous sentence's output, and them accesses split tokens.

"cherry banana apple", split " ", sort them descending, print first.
⚡

Implicit Stdin Streaming (-n)

Pipe standard input into otto -n -c 'print each.'. otto automatically establishes an implicit per-line streaming loop backed by recycled $O(1)$ memory arenas.

cat access.log | otto -n -c 'print 1st word.'
🛡️

Safe Dry-Run & Instant Undo

Preview file mutations with simulate without touching disk. Modifications are auto-journaled in ~/.otto/journal with instant rollback via undo last.

every file "*.conf": simulate inplace replace "old" "new".
undo last.
🗄️

Embedded SQLite Streaming

Stream directly into and out of SQLite database files. Automatic table creation and native pushdown for SQL where filters with zero driver configuration.

every row "ops.db:metrics" where cpu >= 80: print host.
📦

Single-Binary Self Bundler

Turn any .otto script into a standalone, portable, zero-dependency executable. Distribute standalone tools without installing any runtime.

compile "build_tool.otto" into "./build_tool".
⚙️

Process & Job Control

Spawn background tasks asynchronously with background run, inspect active jobs with jobs, table., bring them to the foreground with resume, or terminate with kill.

background run "server" • jobs, table. • kill 1.

Comparison: Traditional CLI Stack vs. otto

Replace dozens of external utilities, arcane flags, and fragile text-scraping pipes with structured sentences.

Classic Unix Stack (Bash + rg + jq + lsof + sed + awk)
otto Shell
Code Search & File Size Filter (rg + find + du)
rg -i "TODO" src/ && find src/ -type f -size +10k -ls
otto Native Search & Unit Literals
search casefold "TODO" in "src", table.
every recursively file "src/*" where each's size > 10kb: print each's name.
Git Inspection & Port Cleanup (git + awk + lsof + kill)
git log -n 5 --pretty=format:"%h %an %s" && kill -9 $(lsof -t -i:8080)
otto Structured Git & Port Scanners
read git commits, take 5, table.
every port where port == :8080: kill.
Stream Aggregation (awk)
awk '{sum += $2} END {print sum}' scores.txt
otto English Stream
before: 0 into s. every line "scores.txt": add 2nd number into s. after: print s.
REST API JSON & Config Parsing (curl + jq + taplo)
curl -s https://api.io/users | jq -r '.[] | select(.age > 21) | .name' | head -n 1
otto Possessive Stream (JSON / YAML / TOML / JSONL)
fetch "https://api.io/users" json, take where each's age > 21, print first's name.
Batch In-Place Replacement (find + sed)
find . -name "*.conf" -exec sed -i 's/8080/9090/g' {} + # No dry-run, no rollback!
otto Transactional In-Place
every file "*.conf": inplace replace "8080" "9090".
# Revert anytime: undo last.
Frequency Tally & Table (sort | uniq -c)
cat access.log | cut -d' ' -f1 | sort | uniq -c | sort -nr
otto Tally Grid
read "access.log", tally, table.
